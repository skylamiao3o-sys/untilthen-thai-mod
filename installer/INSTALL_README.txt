Until Then - ตัวติดตั้งภาษาไทยแบบใช้แรมน้อย

1. เลือกเพียงฟอนต์เดียว: Itim หรือ Sarabun ไม่ต้องติดตั้งทั้งสองชุด
2. แตก ZIP ทั้งหมดก่อน อย่าเปิด INSTALL.bat จากข้างใน ZIP
3. บันทึกและปิดเกม Until Then ก่อน ตัวติดตั้งจะขอให้ Steam ปิดตามปกติ
4. เปิด INSTALL.bat หาก Windows ไม่อนุญาตให้เขียนโฟลเดอร์เกม ให้คลิกขวา Run as administrator
5. รอจนขึ้น DONE ตัวติดตั้งจะตรวจทุกไฟล์ก่อนแทนที่ไฟล์เกม
6. เปิด Steam และเกมเอง แล้วเลือกภาษาไทยใน Settings -> Language

ตัวติดตั้งอ่าน/เขียนไฟล์ทีละส่วนด้วยบัฟเฟอร์ 1 MB และทำงานทีละขั้น
ไม่ต้องลง Python หรือโปรแกรมแพ็กเพิ่ม ใช้ Windows PowerShell 5.1 ที่มีอยู่ใน Windows
ต้องมีพื้นที่ว่างประมาณ 4 GB บนไดรฟ์เกม จะแสดงจำนวนที่ต้องใช้จริงก่อนเริ่ม
เครื่องหรือดิสก์ที่ช้าอาจใช้เวลาหลายนาที โปรดรอให้ตรวจไฟล์เสร็จ
แรม 1 MB คือขนาดบัฟเฟอร์ ไม่ใช่แรมรวมของตัวติดตั้งหรือของ Windows

แบ็กอัปเดิมเก็บไว้ที่ UntilThen.pck.bak และจะไม่ถูกเขียนทับ
ถ้าการติดตั้งล้มเหลว จะหยุดโดยไม่ลองแพ็กซ้ำอัตโนมัติ ดูรายละเอียดใน debug.log
ถ้าเกมเสียจากการติดตั้งครั้งก่อน แต่แบ็กอัปยังสมบูรณ์ ตัวติดตั้งจะสร้างเกมจากแบ็กอัปใหม่
ถ้าแบ็กอัปเสียด้วย ต้องกู้ไฟล์ต้นฉบับจาก Steam ก่อน
ถอนม็อดด้วย UNINSTALL.bat (คืนไฟล์จากแบ็กอัป)
ตัวถอนม็อดจะตรวจสำเนาแบ็กอัปก่อนแทนที่เกม ต้องมีพื้นที่ว่างประมาณ 4 GB เช่นกัน

ถ้าติดขั้นปิด Steam:
- ทั้งตัวติดตั้งและตัวถอนม็อดรอ Steam ไม่เกิน 30 วินาที ไม่มีการวนรอไม่สิ้นสุด
- ถ้ายังปิดไม่สำเร็จ จะหยุดพร้อมแสดง PID ของ Steam และเก็บรายละเอียดใน log
- รอเกม/การดาวน์โหลด/Cloud sync ให้เสร็จ แล้วออกจากไอคอน Steam ข้างนาฬิกา -> Exit
- ถ้า Steam ไม่ตอบสนอง ให้ปิด Steam Client Bootstrapper ใน Task Manager แล้วลองใหม่
- ถ้าสั่งปิดไม่ได้เพราะสิทธิ์ ให้ปิด Steam จากหน้าต่างของมันเองก่อน
- ถ้า Steam ปิดแล้วแต่ไฟล์เกมยังถูกล็อก จะหยุดและบอกชื่อไฟล์ที่เปิดไม่ได้
- ไม่บังคับฆ่าเกม ไม่ปิดบริการ Steam และไม่เปิด Steam กลับเอง

อย่าย้ายเฉพาะ INSTALL.bat ต้องเก็บ install_low_memory.ps1, LowMemoryPck.cs,
detect_game.ps1, steam_guard.ps1, payload.manifest และโฟลเดอร์ payload ไว้ด้วยกัน
ตัวติดตั้ง EXE และ ZIP รุ่นเก่าที่เคยดาวน์โหลดไม่ได้ถูกแก้โดยอัตโนมัติ
